# Hash-pinned bootstrap pip for Dockerfile.graphify (the throwaway, network-
# isolated graphify builder image). This single artifact bootstraps everything
# else in the python-builder stage, so it is cryptographically verified.
#
# `pip install --require-hashes -r requirements-pip.txt` refuses to install unless
# downloaded wheel's sha256 matches the value below — the published PyPI digest
# of pip-26.1.2-py3-none-any.whl — consistent with the digest-pinned base image.
#
# To bump: change BOTH the version and the --hash to the new wheel's published
# PyPI sha256 (pip will hard-fail if they disagree). Kept as its own file so
# Dependabot / CI can track and update the pin automatically.
